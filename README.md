## Instalação

Instale o ODBC

```shell
sudo apt update
sudo apt install odbc-postgresql
```

Clone o repositório

```shell
git clone git@github.com:example/Example.git
```

Instale as dependências

```shell
cd nome-projeto
poetry install
```
